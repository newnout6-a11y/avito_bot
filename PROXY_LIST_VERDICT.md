## Диагноз

Список жив наполовину, но это **HTTP-only прокси**: plain HTTP они проксируют,
а CONNECT-туннелирование для HTTPS не работает ни у одного проверенного.
Это классика бесплатных списков (исследования: HTTPS поддерживают ~2.5%
отзывчивых бесплатных прокси).

**Avito — только HTTPS** (редирект HTTP→HTTPS, API/страницы/sitemap все на TLS).
Вывод: этот список для Avito **бесполезен в лоб**, сколько ни фильтруй.

## Что списком всё же можно

1. **Незашифрованные цели** — 53% живости неплохо: любые http://-сайты,
   проверка доступности, скан лёгких API.
2. **Сырьё для конвейера** proxy_harvest: если когда-нибудь понадобится
   plain-HTTP-пул — уже распарсен и дедупнут (58k адресов).
3. Часть из них, возможно, оживёт на HTTPS со временем (порты слушают) —
   но по замеру сейчас 0%.
