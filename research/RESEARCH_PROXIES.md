# Прокси-ландшафт: полный разбор (субагент-исследование + живые замеры, 27.08.2026)

Четыре параллельных исследования (фундамент/ротация, бесплатные источники,
самостоятельный поиск и фермы, Avito-специфика) + собственная живая промерка
66 бесплатных RU-прокси против Avito. Полные тексты субагентов — в их отчётах
и proxy_landscape_report.md; здесь — синтез и выводы для нашего бота.

## 1. Живая промерка: бесплатный RU-пул против Avito (наш замер)

Забор: geonode API (country=RU, 50 шт, JSON с ASN/anonymity) + ProxyScrape
RU (16 шт) = 66 кандидатов. Каждый через curl_cffi impersonate → avito.ru.

- соединились: **4 из 66 (6%)**
- Avito отдал 200: **2 из 66 (3%)** — 178.217.99.33:3129 (Hosting technology
  LTD, 5.3 c) и 185.212.88.243:8080 (Fly Telecom, 4.4 c)
- Avito отдал 403: 2 — оба датацентр-ASN

Вывод: даже «прошедшие» — датацентровые ASN, медленные (4-5 с на главную) и
сдохнут под нагрузкой. Числа бьют в точку с бенчмарком Olostep (~2.56%
успешных запросов через бесплатные прокси) и исследованиями (8-34% живых
в моменте, HTTPS у 2.5%).

## 3. Ключевые факты по уровням детекции

- **ASN-базы решают всё**: MaxMind GeoIP2 (anonymizer_confidence 1-99),
  IP2Proxy PX11/PX12 (9 типов IP), ipinfo (hosting/vpn/proxy, daily).
  Datacenter = 30-50% блоков на защищённых целях vs <1% residential.
- **Мобильный CGNAT (RFC 6598, 100.64.0.0/10)** — «золото»: 50-1000+ юзеров
  на IP, trust 85-99, Avito не отличает парсера от абонента.
- **Avito = только IPv4**: IPv6 не поддерживается вовсе (3 независимых
  подтверждения) — IPv6-пулы (/64 за $2-4/мес) бессмысленны.
- **Протоколы**: HTTP-прокси светит Via/X-Forwarded-For (transparent/
  anonymous/elite); SOCKS5 без HTTP-метаданных, socks5h = remote DNS.
- **Тихая блокировка**: из 200 DC-IP живыми остались ~40 — и те подмешивают
  мусор в выдачу (отравление данных без кода ошибки).
- **Улика Duff89 issue #283**: серверный прокси + spfa = стабильный 429;
  мобильный + spfa = работает. Тип IP важнее кук.

## 4. Как ищут прокси сами (конвейер)

1. **zmap/masscan** по /0 за <45 мин (1.44-10 Mpps) по портам 8080/3128/1080
   → чекер (echo-эндпоинт httpbin/ip, уровни анонимности, гео, latency)
   → публикация. TheSpeedX/Zmap-ProxyScanner: 2-5k прокси за скан.
2. **Shodan**: `"Squid Proxy" port:3128` ≈ 462k хостов; Censys/ZoomEye аналогично.
3. **Феномен MikroTik**: 13k роутеров как SOCKS-реле (Infoblox 2025),
   900k+ уязвимых; большинство «бесплатных прокси» — криво настроенные
   роутеры и IoT с малварью, 5.15% инъекций злонамеренные.
4. **Агрегатор-инфра**: jhao104/proxy_pool (23.6k★): fetcher→Redis→валидатор
   →API :5010, docker одной командой. Для незащищённых целей — готовый конвейер.

## 5. Что внедряем в проект

1. **proxy_harvest.py** — утилита-воплощение «как их ищут»: забор из
   geonode+ProxyScrape+proxifly (RU-шарды), проверка против Avito,
   экспорт живых в формат AVITO_PROXIES. Для Avito — аварийный пул
   (3% прохода), для незащищённых целей — рабочий конвейер.
2. Подтверждение курса: **домашний IP + наш стек** = правильный нулевой
   бюджет (уровень 2 пирамиды). Следующий апгрейд при необходимости —
   один 4G-модем (уровень 3), он же встанет в существующие
   AVITO_PROXIES + AVITO_PROXY_CHANGE_URLS без правок кода.
