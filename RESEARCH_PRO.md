# Профи-исследование: как «крутые» парсят Авито (2025–2026)

Сводка по итогам живых проб + форумов + коммерческих обзоров. Дополняет
PoW-решатель (avito_pow.py), который уже снимает уровень JS-challenge.

## Картина уровней (что уже закрыто и чем)

| Уровень | Механика | Статус у нас |
|---|---|---|
| Транспортный (TLS/JA3) | curl_cffi impersonate | ✅ закрыт |

## Что делают коммерческие сервисы (Avtoringer, Multiscan, SCANURIK)

- **Потолок скорости: 3–5 сек** между проверками (Avtoringer PRO «3 сек»,
  кейс «Дмитрий»: 5 сек). Никто не даёт <3 сек.
- Держат такой темп **пулами резидентных/мобильных IP** (4G-модемы, «чистые» IP)
  и ротацией аккаунтов каждые 2–3 дня (VK-статья «Секрет перекупов»).
- Веб-интерфейс + Telegram-бот, тарифы 500–1000 ₽/мес.
- Multiscan заявляет «ежесекундную выгрузку» — маркетинг; реально интервалы
  сопоставимы с Avtoringer (vc.ru-обзор ставит SCANURIK быстрее Multiscan).

Вывод: их преимущество — не магия обхода, а **инфраструктура IP**. Без мобильных
прокси (наш случай) сравняться можно только дисциплиной темпа: 30–60 сек
интервал с домашнего резидентного IP + cookie-репутация = устойчиво и бесплатно.

## Whitelist-паразитизм (форум searchengines.guru, -= Serafim =-)

Цитата про Avito: «у них бот яндекса и гугла в вайтлисте — поисковикам вайтлист,
а остальных на js проверку». Техника: получать контент через инфраструктуру
поисковиков, которые Avito не банит.

Опробовано живьём:

- **Google PageSpeed Insights API** — Google сам заходит на URL. Работает, но:
  дневной shared-лимит без ключа исчерпан мгновенно; отчёт не отдаёт полный HTML
  (только скриншот/метрики). Подходит как аварийный канал «жива ли страница».
- **r.jina.ai reader** — вернул 200, но Avito отдал ему блок-страницу
  (датацентровые IP Jina под баном). Для Avito непригоден.
- **allorigins / codetabs** (CORS-прокси) — 522, их серверы не тянут Avito.

Вывод: whitelist-вектор для регулярного мониторинга мёртв — датацентровые IP
всех бесплатных посредников уже в бане, а полный контент они не отдают.

## Лазейка «до модерации» (VK-статья, проверена частично)

«Авто-отклонённые объявления (5–10% потока) всё ещё доступны для парсинга» —
объявления, помеченные как подозрительные, до полной модерации видны в выдаче.
Модерация Avito теперь 2–5 минут, сервисы «до публикации» (edrom) умерли.

Практический смысл: `sort=date` в нашем API URL уже отдаёт самое свежее,
включая ещё не полностью промодерированное — отдельного параметра статуса
в `/web/1/js/items` не обнаружено (в ответе есть флаги у item).

## Мобильный API (мертв)

`m.avito.ru` → 301 на www. `/api/9..11/items` → 429/403/302 — тот же Qrator,
отдельной «дыры» больше нет. Старый публичный ключ мобильного API
(`af0deccbgcgid...`) больше не работает без тех же challenge.

## Эталон сравнения: Duff89/parser_avito (708 звёзд, docs 15.06.2026)

Их официальные «проверенные» варианты обхода:
- мобильный прокси — «работает, но много блокировок»
- мобильный прокси + **spfa.pro (платные cookies, ~12 ₽ / 12 ч)** — «работает хорошо»
- серверный прокси + spfa — «работает хорошо»

Т.е. самый популярный открытый парсер России решает проблему платными куками
и прокси. Наш PoW-решатель снимает тот же challenge бесплатно, а cookie
persistence заменяет их «поддержку кук 12 часов» собственным накоплением.

## Итоговая формула нулевых расходов (наш стек)

1. curl_cffi `safari15_5` (TLS) — есть
2. PoW-решатель 439 — есть, 0.1–0.3 c на challenge
3. Cookie persistence между запусками — добавлено (data/cookies_<route>.json):
   тёплая сессия, репутация копится, прогрев пропускается
4. Backoff ip_block 20 мин база / cap 2 ч — добавлено (Qrator не шлёт
   Retry-After, долбить в бан = продлевать бан)
5. Темп 30–60 сек + jitter — уже было

Этого достаточно, чтобы без прокси и платных кук держать мониторинг
бесплатно и не отличаться от внимательного покупателя с браузером.
